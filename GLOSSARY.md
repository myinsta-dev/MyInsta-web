# MyInsta translation glossary

These terms identify the product, platform, or a technical value that users
must recognize consistently. Keep the protected spelling in every locale.

| English term | Handling |
| --- | --- |
| MyInsta | Keep exactly `MyInsta`. |
| Instagram | Keep exactly `Instagram`. |
| Android | Keep exactly `Android`. |
| APK | Keep exactly `APK`; inflect the surrounding sentence if needed. |
| ABI | Keep exactly `ABI`. |
| ARM64 / ARM32 | Keep exactly `ARM64` and `ARM32`. |
| x86 / x86_64 | Keep exactly `x86` and `x86_64`. |
| SHA-256 | Keep exactly `SHA-256`. |
| Google Play / Play Store | Keep exactly as written. |
| Ghost Mode | Keep the product feature name in English unless a native reviewer supplies a documented local display name. |
| Story / Stories | Translate as a social media feature when the sentence is clearly user-facing; keep `Story` in screenshot identifiers and URLs. |
| Release | Translate according to local software-release usage, not as a physical product release. |

The validator checks the case-sensitive protected terms. If a locale needs a
documented exception, update this glossary and the validator policy in the
same reviewed change.
