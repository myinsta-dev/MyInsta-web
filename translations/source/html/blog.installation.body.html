APK variants

In order to support a wide range of devices, the app has many variants. You can find information regarding the variant you should install on your device below.

  • ARM64: This is the variant you most likely have to install if you are using a modern, 64 bit, device

  • ARM32: This is less common nowadays and is targeted to older, 32 bit, devices

  • x86_64 & x86: This is meant for emulators and will not work on regular phones.

Some phones, like some Google Pixels, have backward compatibility meaning you will be able to install the 32 bit version on 64 bit devices. You should still install the ARM64 variant on these devices to prevent any bugs that may occur from this compatibility layer. In addition to that, emulators also have a compatibility layer allowing you to install ARM versions on them. Some may even refuse to install the x86 versions, although this is less common and limited to older versions of them.

Installation issues

  • "App not installed as app isn't compatible with your phone": You are trying to install an unsupported variant. Check above for instructions on finding the correct variant

"App not installed as package conflicts with an existing package": This error occurs when you have an existing version of the app installed and the new version you are trying to install has a different signature. Some phones come with Instagram preinstalled as a system app, disallowing users from uninstalling it (And thus installing the unclone version). There are ways around this that typically require a computer. If you don't want to go through that process, resort to the clone version.

Website errors

"Your connection is not private" browser error: Some browsers can ignore this warning and proceed to our website via the advanced options. For those who don't, you will need to change your DNS (Google's and Cloudflare's are compatible) or use a VPN. This warning generally should not be overlooked. On our website, where you don't submit any credentials, it is safe to ignore it and work around it.

"Too many downloads attempts" and other errors: This is a restriction to maintain website speed on high demand times. Other errors with the same format are self explanatory.
