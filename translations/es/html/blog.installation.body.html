Variantes de APK

Para admitir una amplia variedad de dispositivos, la aplicación tiene muchas variantes. A continuación encontrarás información sobre la variante que debes instalar en tu dispositivo.

  • ARM64: Esta es la variante que probablemente tendrás que instalar si usas un dispositivo moderno de 64 bits.

  • ARM32: Hoy es menos habitual y está destinada a dispositivos antiguos de 32 bits.

  • x86_64 & x86: Está pensada para emuladores y no funcionará en teléfonos normales.

Algunos teléfonos, como ciertos Google Pixel, tienen compatibilidad con versiones anteriores, lo que permite instalar la versión de 32 bits en dispositivos de 64 bits. Aun así, debes instalar la variante ARM64 en estos dispositivos para evitar errores que pueda causar esta capa de compatibilidad. Además, los emuladores también tienen una capa de compatibilidad que permite instalar versiones ARM en ellos. Algunos incluso pueden negarse a instalar las versiones x86, aunque es menos habitual y se limita a emuladores antiguos.

Problemas de instalación

  • «La aplicación no se ha instalado porque no es compatible con tu teléfono»: Estás intentando instalar una variante no compatible. Consulta las instrucciones anteriores para encontrar la variante correcta.

«La aplicación no se ha instalado porque el paquete entra en conflicto con un paquete existente»: Este error aparece cuando ya tienes instalada una versión de la aplicación y la nueva versión que intentas instalar tiene una firma diferente. Algunos teléfonos incluyen Instagram preinstalado como aplicación del sistema, lo que impide desinstalarlo (y, por tanto, instalar la versión unclone). Hay formas de evitarlo que normalmente requieren un ordenador. Si no quieres seguir ese proceso, usa la versión clone.

Errores del sitio web

Error del navegador «Tu conexión no es privada»: Algunos navegadores pueden ignorar esta advertencia y continuar hasta nuestro sitio web mediante las opciones avanzadas. En los que no lo permitan, tendrás que cambiar tu DNS (los de Google y Cloudflare son compatibles) o usar una VPN. Por lo general, no debes ignorar esta advertencia. En nuestro sitio web, donde no introduces credenciales, es seguro ignorarla y continuar.

«Demasiados intentos de descarga» y otros errores: Es una restricción para mantener la velocidad del sitio web durante los periodos de mucha demanda. Los demás errores con el mismo formato se explican por sí solos.
