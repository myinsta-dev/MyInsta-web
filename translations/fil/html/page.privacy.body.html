Patakaran sa privacy ng website

Maaaring mag-load ang aming website ng mga script ng Google Analytics na naka-host sa mga server ng Google. Ginagamit namin ang mga script na ito upang subaybayan ang anonymized traffic analytics at hindi kami nag-iimbak ng impormasyong makapagpapakilala sa mga user. Basahin ang Patakaran sa privacy para sa mga partner site ng Google.

Nagbibigay ang Cloudflare ng content delivery at proteksyon laban sa mga cyberattack. Basahin ang Patakaran sa privacy ng Cloudflare.

Patakaran sa privacy ng app

Hindi gumagawa ang MyInsta ng mga independent network request maliban kung resulta ito ng mga pagkilos ng user, gaya ng pagsuri ng mga update. Naka-configure ang MyInsta na magsuri ng mga update sa startup o kapag nire-refresh ang app, kaya nagkakaroon ng isang request para makuha ang impormasyon ng pinakabagong bersyon.

Hindi responsable ang MyInsta at mga developer nito sa mga request na likas na ginagawa ng Instagram. Basahin ang patakaran sa privacy ng Instagram.

Mga eksepsiyon

Ang patakarang ito sa privacy ay hindi naaangkop sa mga third-party o hindi opisyal na distribusyon ng MyInsta. I-verify ang na-download na file sa pamamagitan ng paghahambing ng hash nito sa mga hash na ibinigay para sa mga release sa aming pahina ng release.

Seguridad

Sinisikap namin nang makatuwiran ang lahat upang protektahan ang aming mga user at mapanatili ang seguridad ng MyInsta. Gayunpaman, walang system o service sa Internet na maaaring garantisadong ganap na ligtas o walang kahinaan. Sa paggamit ng MyInsta, kinikilala mong hindi maaaring panagutin ang mga Developer at MyInsta Team para sa mga insidente sa seguridad na nagaganap lampas sa kanilang kontrol.
