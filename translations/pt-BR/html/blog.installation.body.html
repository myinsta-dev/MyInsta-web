Variantes de APK

Para oferecer suporte a uma grande variedade de dispositivos, o app tem várias variantes. Você encontra abaixo informações sobre a variante que deve instalar no seu dispositivo.

  • ARM64: esta é a variante que você provavelmente precisará instalar se estiver usando um dispositivo moderno de 64 bits

  • ARM32:esta é menos comum hoje em dia e é destinada a dispositivos mais antigos de 32 bits

  • x86_64 & x86:esta variante é destinada a emuladores e não funcionará em telefones comuns.

Alguns telefones, como alguns Google Pixels, têm compatibilidade retroativa, o que significa que você poderá instalar a versão de 32 bits em dispositivos de 64 bits. Ainda assim, instale a variante ARM64 nesses dispositivos para evitar bugs que possam ocorrer nessa camada de compatibilidade. Além disso, os emuladores também têm uma camada de compatibilidade que permite instalar versões ARM neles. Alguns podem até se recusar a instalar as versões x86, embora isso seja menos comum e esteja limitado a versões mais antigas dos emuladores.

Problemas de instalação

  • "O app não foi instalado porque não é compatível com seu telefone": você está tentando instalar uma variante sem suporte. Consulte as instruções acima para descobrir a variante correta

"O app não foi instalado porque o pacote entra em conflito com um pacote existente": esse erro ocorre quando você já tem uma versão do app instalada e a nova versão que está tentando instalar tem uma assinatura diferente. Alguns telefones vêm com o Instagram pré-instalado como app do sistema, impedindo os usuários de desinstalá-lo (e, portanto, de instalar a versão unclone). Existem maneiras de contornar isso que normalmente exigem um computador. Se não quiser passar por esse processo, use a versão clone.

Erros do site

Erro de navegador "Sua conexão não é privada": alguns navegadores podem ignorar esse aviso e prosseguir para o nosso site usando as opções avançadas. Para os que não podem, será necessário alterar seu DNS (os serviços do Google e do Cloudflare são compatíveis) ou usar uma VPN. Em geral, esse aviso não deve ser ignorado. No nosso site, onde você não envia credenciais, é seguro ignorá-lo e contorná-lo.

"Muitas tentativas de download" e outros erros: esta é uma restrição para manter a velocidade do site em períodos de alta demanda. Outros erros com o mesmo formato são autoexplicativos.
